# Prismotive

**Colour in motion.**

Prismotive is a lightweight, framework-independent
TypeScript library for animated borders, flowing waves,
and interactive cursor trails with customisable colour themes.

## Project Status

Prismotive is currently under active development.

The package is not yet available for production use.

## Planned Features

- Animated gradient borders
- Animated Canvas-based waves
- Interactive cursor trails
- Five built-in colour themes
- Custom colour palettes
- Animation lifecycle controls
- TypeScript support
- Framework-independent API
- Accessibility and reduced-motion support

## Built-in Themes

- Rainbow
- Ocean
- Sunset
- Aurora
- Gold

## Technology

- TypeScript
- CSS Animations
- Canvas 2D
- Vite
- Vitest
- Playwright
